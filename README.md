# ABE'S AVE. Productions

A cinematic editorial website for **ABE'S AVE. Productions — Stories. People. Culture.**

## Creative direction
The experience is built around the idea that **every story has an address** and every project is another stop along *The Avenue*. It uses original editorial compositions, cinematic pacing, restrained motion, street-sign-inspired language and the brand palette:
- Off-White #F5F1E8
- Teal Green #0F6B63
- Dark Orange #C65A24
- Red #A83232
- Dark Grey #252525

## Stack
React + Vite + Lucide Icons

## Run
npm install
npm run dev

## Assets
The current build uses art-directed visual placeholders so the structure and motion can be reviewed immediately. Replace the project/photo backgrounds with real production stills and uploaded ABE'S AVE. logo assets when those files are available in the repository.
